Cloud Sync (via Dropbox / Google Drive / OneDrive)

This tool has no server, so it can't sync automatically over the internet on its own. What it can do is read and write one file that lives inside a folder your cloud storage app (Dropbox, Google Drive, OneDrive, etc.) already syncs between your devices — the cloud app moves the bytes; this just knows how to read and write that one file. Set it up once per device, then click "Save to Sync File" before switching machines and "Load from Sync File" after you switch.
Works in Chrome, Edge, and other Chromium browsers. Not supported in Firefox or Safari — on those, use "Export All Cases" / "Import Case(s)" in the bottom bar instead, saving or opening the file from inside your cloud-synced folder; the effect is the same. Either way this is manual sync, triggered by you, not automatic or real-time — if you edit the same case on two devices before syncing, whichever save happens last will overwrite the other, so it's safest to treat one device as primary at a time.
